# Templates

Bootstrap material for new TinsuAI repos. Copy into a fresh repo,
fill the placeholders.

Contents (planned):

- `AGENTS.md.tmpl` — project-instructions skeleton with required
  sections.
- `pyproject.toml.tmpl` — Python project skeleton.
- `.github/workflows/ci.yml.tmpl` — CI/CD seed matching
  `policies/ci-cd.md`.
- `deploy/docker-compose.yml.tmpl` — Compose seed matching
  `policies/release-engineering.md` Tier-D shape.

> **Status: empty.** Will populate after the first new repo
> scaffolds against this standards repo. The intent is to extract
> templates from real seed work, not write speculative ones.
