# Code style policy

> **Status: stub.** Awaiting RFC.

This file will codify cross-product code-style baselines:
indentation, naming, language-specific conventions (Python, JS/TS,
SQL, YAML), commit-message style, minimum lint config.

Until then, each repo follows its own per-product conventions noted
in the repo's `AGENTS.md` ("Conventions" section). The current
defaults across products:

- 4 spaces Python, 2 spaces YAML / JSON / TS.
- Commit messages in English; no `Co-Authored-By` trailer.
- Vietnamese comments only where domain terms have no English
  equivalent.

When ready to fill this in, open an RFC under `proposals/`.
