# Proposals (RFCs)

In-flight or historical RFCs. See [CONTRIBUTING.md](../CONTRIBUTING.md)
for the change flow.

File naming: `YYYY-MM-DD-<slug>.md`.

Each RFC carries a status header (`draft` / `in review` / `accepted`
/ `rejected` / `superseded`). Once a status reaches `accepted` and
the corresponding policy file is updated, the RFC stays here as the
historical record — do not delete or rewrite it.
